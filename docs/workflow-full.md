## 一、整體流程（標準化步驟）⚠️ 2026-07-13 更新

```
Mike說「生成今日施工記錄表」
    ↓
1. 找到最近一日的記錄表 docx（如 2026-07-09每日施工記錄表.docx）
    ↓
2. 複製昨日文檔 → 改名為今日日期
    ↓
3. 只修改會變的欄位：
   - 記錄日期 → 今日
   - 開工第幾天 → 昨日+1
   - 天氣 → 從SMG天氣報告PDF提取
   - 潮汐低潮/高潮 → 從SMG潮汐預報PDF提取
   - 施工階段 → 按Mike當日描述（保留編號前綴如「C」）
   - 施工項目(1~3) → Mike提供
   - 警戒潮位 → 根據當日高潮值判斷（≥3m → ☑是；<3m → ☑否）
   - 不符合施工條件 → 全部改回 ☑是（每日重設）
    ↓
4. 不變的欄位原樣保留：
   - checkbox 狀態（安全自檢全部保持勾選）
   - 表格結構（行數/列數）
   - 格式/字體/排版
   - 記錄人：[建築公司名稱]
   - 進場/離場時間（默認 09:00 / 18:00）
    ↓
5. 自動掃描附件\現埸相\YYYY-MM-DD 目錄
    ↓
6. 有照片 → 嵌入表格5（清除舊照片後插入新照片）
    ↓
7. 無照片 → 保留昨日照片或清除為空白
    ↓
8. 交付 docx 給 Mike 確認（天氣/潮汐數值需核實）
    ↓
9. 🔴 自動轉 PDF + 合併天氣/潮汐報告（Mike 2026-07-21 確立，每次必執行）
   a. docx → PDF（docx2pdf / Word COM）
   b. PDF 合併：施工記錄表 + 天氣報告 + 潮汐預報 → 完整版 PDF
   c. 刪除純施工記錄 PDF，完整版改名為「YYYY-MM-DD每日施工記錄表.pdf」
    ↓
10. 交付最終版 PDF 給 Mike（含天氣+潮汐報告的完整記錄）
```

### ⚠️ 為什麼不再用空白模板？

| 空白模板方案（舊） | 複製昨日文檔方案（新 ✅） |
|:---|:---|
| 每次從零開始，大量隱含資訊丟失 | 繼承昨日所有格式和狀態 |
| checkbox 可能回到未勾選狀態 | checkbox 保持昨日正確狀態 |
| 表格行數/結構每次需重設 | 表格結構與昨日一致 |
| 施工階段編號前綴容易漏（如漏了「C」） | 階段前綴從昨日繼承 |
| 開工天數需手算，很容易算錯 | 昨日天數+1，幾乎不可能錯 |
| **已被 Mike 否定**（2026-07-13） | ✅ 當前標準流程 |

## 三、欄位修改規則（2026-07-13 更新）

### 每次都改的欄位
| 欄位 | 新值來源 |
|:---|:---|
| **記錄日期** | 今天 YYYY-MM-DD |

| **完成情況** | 進行中 / 已完成 |

## 五、照片處理流程

### 目錄規範
```
每日施工記錄\
├── 附件\
│   └── 現埸相\
│       └── YYYY-MM-DD\
│           ├── 圖一.jpg
│           ├── 圖二.jpg
│           ├── 圖三.jpg
│           └── 圖四.jpg
```

### 嵌入規則（新：替換昨日照片）
- 自動掃描 `附件\現埸相\YYYY-MM-DD\` 目錄
- **先清除表格5所有儲存格內的舊照片**
- 按圖一→R0C0、圖二→R0C1、圖三→R1C0、圖四→R1C1 嵌入新照片
- 🔴 **圖片尺寸強制規格：width=2.6inch, height=2.0inch（確保四張照片在一頁紙內）**
- ❌ 禁止使用 2.8inch 寬度（過大，四張會溢出頁面 → Mike 已糾正 2026-07-31）
- 若無照片目錄或無文件，清除照片區域留空

### 注意事項
- 照片文件較大（3~12MB），嵌入後 docx 體積會增大
- 若無照片目錄或無文件，清除舊照片區域，保留為空

## 七、OfficeCLI 自動化探索（2026-06-29）

### 測試結論：❌ 不可行

| 嘗試 | 結果 |
|:---|:---|
| 複製模板 | ✅ 成功 |
| query 讀取結構 | ✅ 成功，拿到完整表格XPath |

| merge 命令 | ❌ 未測試（SIGKILL 後終止） |

### 根本原因
OfficeCLI 對 **含複雜表格的 Word 文檔** 處理不穩定，尤其是在：
- 合併儲存格（merged cells）
- 巢狀表格
- 大量格式設定

### 替代方案
- **python-docx**：✅ 穩定可靠，填表+插圖+生成一氣呵成
- **複製昨日文檔+python-docx修改**：當前最優方案（2026-07-13起）
