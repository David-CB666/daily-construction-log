---

## 🔴 核心規則（不可違反）

### 圖片尺寸
```python
width=Inches(2.6), height=Inches(2.0)
```

> **原因**：Mike 2026-07-31 明確指出 2.8" 寬度過大，四張照片無法完整顯示在一頁紙內。2.6"×2.0" 為最終確定規格，已寫入流程手冊。

### 對齊
```python
p.alignment = WD_ALIGN_PARAGRAPH.CENTER
```

---

## 📸 圖片來源
```
每日施工記錄\附件\現埸相\YYYY-MM-DD\
```

### 支援的命名格式

| 格式 | 示例 | 出現日期 |
|:--|:--|:--|
| 圖一~圖四.jpg | 圖一.jpg, 圖二.jpg, ... | 常規 |
| 圖 (1)~(4).jpg | 圖 (1).jpg, 圖 (2).jpg, ... | 2026-08-01 |

---

## 🔄 嵌入邏輯

```
圖片1 (圖一) → 表格5, Row 0, Cell 0
圖片2 (圖二) → 表格5, Row 0, Cell 1
圖片3 (圖三) → 表格5, Row 1, Cell 0
圖片4 (圖四) → 表格5, Row 1, Cell 1
```

### 處理順序
1. 掃描 `附件\現埸相\YYYY-MM-DD` 目錄
2. **先清除表格5所有儲存格內的舊照片**（run.clear都不夠，要 paragraph.clear()）
3. 按映射嵌入新照片
4. 若無照片目錄 → 清除表格5留空

---

## ⚠️ 注意事項

- 照片文件可能很大（3~12MB JPEG），嵌入後 docx 體積會增大
- 但規格固定後文件大小可控（通常30~45MB含4張照片）
- 必須在清除舊照片後才嵌入新照片，否則重複累積
