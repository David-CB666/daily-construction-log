# Contributing

Thanks for your interest in contributing! This project was built from real construction workflows — improvements from the community make it better for everyone.

## How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/new-feature`)
3. Commit your changes (`git commit -m 'Add new feature'`)
4. Push to the branch (`git push origin feature/new-feature`)
5. Open a Pull Request

## Guidelines

- Keep the "copy yesterday" strategy — do not switch to a blank-template approach
- Photo size must remain 2.6" × 2.0" (ensures 4 photos fit on one page)
- Preserve all checkbox states from yesterday's document
- Test with real .docx files before submitting
- Desensitize any real project names, company names, or file paths in your changes
